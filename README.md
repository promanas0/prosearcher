# Ritual Tx Searcher & Network Explorer Tool

a lightweight network utility dApp for the Ritual Network ecosystem, allowing users to track transactions and inspect chain activity.

## Key Features
- **Transaction Hash Lookup:** Instant transaction status and hash search functionality.
- **Network Explorer Integration:** Directly connects queries to official Ritual chain state.
- **Developer Utilities:** Fast access to network metrics and RPC status queries.

## Purpose
Built to enhance ecosystem transparency and provide quick transaction verification for developers and users on Ritual Network.
